Exécuter dans un laboratoire local

Depuis le dépôt Swarm, utiliser un binaire déjà construit et son empreinte exacte. Choisir un dossier neuf dont le parent existe. Python et Git sont requis. Cette page ne lance aucune commande.

python3 tools/paea/run_pilot.py --binary /CHEMIN/BINAIRE --sha256 SHA256 --output /DOSSIER/NEUF

La commande conserve les sorties et les oracles, vérifie la recette, puis crée paea-lab-report.json seulement après huit tests réussis. Un échec conserve les preuves ; corriger sa cause et reprendre dans un nouveau dossier.

Scénarios et limites
  • T04 : contenu substitué refusé, JSON équivalent accepté.
  • T06/T21 : crash après effet, UNKNOWN, rapprochement et absence de duplication.
  • T05/T17 : première utilisation après révocation refusée ; ordre inverse conservé. Ordres déterministes, pas une course distribuée.
  • Oracle indisponible, référence Git périmée ou symbolique, échec de sortie : refus et reprise observés.
  • Deux aliases bruts produisent deux effets : cela réfute l’unicité par identifiant brut. Deux aliases résolus convergent vers un seul effet dans la fixture coopérante.
