# KS plan — compatibility preparation command

Read `tools/agent-workflows/CONTRACT.md`. From the current brief, build a bounded
plan in the format required by Swarm. In a native session, `spec-builder` provides
the full method. In Swarm preparation, only propose the requested structured output.

For each task name its stable ID, linked requirements, owner role, scope/files,
dependencies, deliverable, acceptance checks and failure/recovery route. Identify
planning and independent review responsibilities. Check dependency cycles,
overlapping writes, provider/workspace capabilities, budgets and missing evidence.
Preserve history when revising a plan. State unresolved decisions and their impact.
Do not implement the plan, claim adoption or call a proposed task completed.
