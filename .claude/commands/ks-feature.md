# KS feature — compatibility preparation command

Read `tools/agent-workflows/CONTRACT.md`. Analyze the requested need using supplied
evidence. In a native session, use `spec-builder` for the full specification method.
In Swarm preparation, stay within its tool-free structured response contract.

Specify the user problem, expected outcome, scope/exclusions, existing decisions,
stable requirement IDs, observable acceptance criteria and material unknowns.
Cover relevant web/CLI parity, role boundaries, failure/recovery, budgets and
independent review. Express what happens for valid and invalid preconditions.
Do not invent evidence, execute changes, start agents or accept a proposed brief.
Pass these requirements to the plan phase; reuse answers already supplied.
