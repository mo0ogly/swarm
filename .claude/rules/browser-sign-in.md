# Connexion à Swarm dans le navigateur

Pour ouvrir ou vérifier le cockpit Swarm, utiliser le navigateur. Si l’instance
propose la connexion par identifiant et mot de passe, ouvrir sa page
`/login`, remplir le formulaire avec le compte autorisé, le soumettre et
vérifier à l’écran l’arrivée dans le cockpit avec les droits attendus. Pour
un contrôle qui ne porte pas sur la connexion elle-même, une session déjà
ouverte avec le bon compte peut être réutilisée.

Si les identifiants sont indisponibles, laisser l’utilisateur se connecter
dans le navigateur. Garder les mots de passe, clés et cookies hors du chat,
des commandes, des preuves et des journaux. Si l’instance propose un autre
mode de connexion, signaler son mode réel et suivre le parcours officiel
affiché dans le navigateur.

Réserver les appels directs à l’API, les cookies injectés et les sessions
techniques aux vérifications explicitement prévues pour ces mécanismes.
Ces vérifications ne valident pas le formulaire de connexion. Si le
formulaire échoue, conserver le diagnostic et laisser ce contrôle ouvert.
