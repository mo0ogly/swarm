# Swarm v0.1.0 — graph editing and durable automation

October 6, 2026. First experimental release. Linux is the qualified installation platform.

## English

Swarm combines probabilistic AI agents with a deterministic orchestration engine. Agents plan, implement and review; the engine enforces authorized transitions, dependencies, workspace reservations, configured limits and evidence freshness throughout the work.

### Included

- **Editable dependency graph:** preview changes, reject cycles and conflicting revisions, then apply through the same guarded service used by the CLI.
- **Durable automation:** manual requests, one-time/daily/weekly schedules, IANA time zones, explicit catch-up policy, deduplication and restart recovery.
- **Controlled external events:** scoped HMAC authentication, timestamp validation, configurable size/rate limits, secret rotation and revocation.
- **Administration:** configurable graph performance, automation parameters, call limits and review timeout; French/English interface and dark/light themes.
- **Observable validation:** current evidence distinguished from historical acceptance, real required checks and separate independent review.
- **Audited contract recovery:** explicit confirmation and a paused mission allow a constrained criteria revision for a blocked hierarchical task. Previous refusals and usage remain visible; changed criteria require fresh checks and review.
- **Installation and rollback:** version metadata in CLI/web, private migration backups on the corrected v18–v27 paths, isolated native upgrade/rollback checks and updated installation guides.

### Verification and limits

The final engine candidate was checked across 1,052 discovered Go tests: 1,044 passed and eight named optional tests were skipped. Qualification also included race checks, vet, frontend/configuration checks and actual browser recipes in French/English and dark/light themes. After a timeout, only the unfinished test shard was continued; the original failure remains in the local history. Release packaging has its own manifest and targeted checks.

These tests use isolated roots and fixtures. They do not demonstrate unattended real-provider autonomy. Provider usage can be incomplete and cost remains unknown when the provider does not report it. Quotas consumed in external Claude Code, Codex or other provider sessions are not automatically visible to Swarm. Exactly-once effects in external systems are not guaranteed. Rollback must restore compatible data and binary together when a schema is incompatible.

### Install

Use the source archive attached to the GitHub release, or clone the repository and check out `v0.1.0`:

```sh
git clone https://github.com/mo0ogly/swarm.git
cd swarm
git checkout v0.1.0
./install.sh --mode native --bin-dir "$HOME/.local/bin"
```

The `swarm-v0.1.0-linux-amd64.tar.gz` asset contains a compiled Linux amd64 binary and these notes. Verify it against `SHA256SUMS` before extracting. AI provider tools and their authentication are configured separately. See [installation](../en/INSTALL.md), [user guide](../en/USER-GUIDE.md), [programs](../en/AUTOMATION-PROGRAMS.md) and [contract recovery](../en/CONTRACT-REVISION.md).

## Français

Swarm associe des agents IA probabilistes à un moteur d’orchestration déterministe. Les agents planifient, réalisent et examinent ; le moteur contrôle les transitions autorisées, dépendances, espaces, limites configurées et preuves pendant tout le travail.

### Nouveautés

- **Graphe éditable :** prévisualisation, refus des cycles et conflits, puis application avec les mêmes gardes que le CLI.
- **Automatisation durable :** demandes manuelles, départs uniques/quotidiens/hebdomadaires, fuseaux IANA, rattrapage explicite, déduplication et reprise après redémarrage.
- **Événements externes contrôlés :** signature HMAC, timestamp, limites de taille/fréquence configurables, rotation et révocation du secret.
- **Administration :** performances du graphe, paramètres d’automatisation, limites d’appels et délai de revue configurables ; interface français/anglais, thèmes sombre/clair.
- **Validation observable :** distinction entre preuves actuelles et acceptations historiques, contrôles réels et revue indépendante séparée.
- **Reprise tracée des contrats :** confirmation explicite et mission en pause pour réviser uniquement les critères admissibles d’une tâche hiérarchique bloquée. Refus et consommation restent conservés ; nouveaux contrôles et nouvelle revue sont obligatoires.
- **Installation :** version CLI/web, sauvegardes privées sur les chemins de migration v18–v27 corrigés, contrôles d’installation native et retour arrière, documentation actualisée.

### Preuves et limites

Le candidat final du moteur a été vérifié sur 1 052 tests Go découverts : 1 044 réussites et huit exclusions optionnelles nommées. La qualification comprend aussi race, vet, frontend/configuration et des recettes navigateur réelles dans les deux langues et thèmes. Après un timeout, seul le groupe de tests inachevé a été repris ; l’échec initial reste dans l’historique local. La préparation de release dispose de son propre manifeste et de contrôles ciblés.

Les essais utilisent des espaces isolés et des fixtures : ils ne démontrent pas une autonomie réelle sans supervision chez les fournisseurs. L’usage peut être incomplet et un coût non rapporté reste inconnu. Les quotas consommés dans les sessions externes Claude Code, Codex ou d’autres fournisseurs ne sont pas automatiquement visibles. Les effets externes « exactement une fois » ne sont pas garantis. En cas de schéma incompatible, un retour arrière restaure ensemble les données et le binaire compatibles.

La procédure ci-dessus installe depuis le tag `v0.1.0`. L’archive binaire est qualifiée pour Linux amd64 ; vérifier `SHA256SUMS` avant extraction. Les outils IA et leur authentification se configurent séparément.
