1. **Ne pas réimplémenter la coordination de revue.** Le contrat `review-plan` couvre déjà inventaire fichiers/critères, DAG, budget, persistance et synthèse finale. La nouvelle livraison devrait l'intégrer ou expliciter la différence entre lots de contrôles déterministes et lots d'inspection qualitative.
2. **Ne pas confondre trois couches.** QW5–QW8 sont déjà dans le candidat sale ; le recontrôle de validation et la recette finale sont des ajouts plus récents non suivis ; la coordination de revue est dans HEAD. Toute gate doit inventorier ces trois provenances.
3. **Candidat non auto-contenu tant que les non-suivis ne sont pas liés.** Les tests essentiels `validation_recheck_test.go`, `validation_recovery_guard_test.go`, `tests/supervision_go_suite.py` et `tests/supervision_final_acceptance.py` sont non suivis. Une empreinte du seul `git diff` ne les couvre pas.
4. **Le texte adopté de `req-1..req-7` manque dans le contexte T1.** Le planificateur doit fournir le mapping normatif avant d'affecter des corrections ; le tableau actuel est un inventaire de couverture, pas une modification de plan.
5. **Suite finale unique.** Les contrôles ciblés servent le développement ; la recette complète doit être exécutée une seule fois sur le candidat figé, puis réexécutée seulement après correction pertinente.
6. **Anciennes missions intouchables.** `w-01567e073c1ed2f3d4c71c9e` reste historiquement 5/6 dans sa consolidation ; la mission suivante est clôturée selon son diagnostic public. Aucune ne doit servir de fixture mutable.
