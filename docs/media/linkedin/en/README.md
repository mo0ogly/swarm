# Swarm — English LinkedIn carousel

Ten portrait pages introducing agent coordination, responsibilities, dependencies,
preparation, acceptance and AI connections.

- [PDF for LinkedIn](swarm-linkedin-en.pdf)
- [Editable PowerPoint](swarm-linkedin-en.pptx)
- [Ten PNG pages](swarm-linkedin-en-images.zip)

Screenshots show the English interface with an isolated, fictional English demo
mission. The demonstration is paused: no agents were launched and no results are
presented as validated. The PDF preserves the reviewed page images; use the
PowerPoint to edit slide text and diagrams.
