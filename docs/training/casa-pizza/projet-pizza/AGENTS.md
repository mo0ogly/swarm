# Atelier Casa Pizza

Réaliser uniquement le besoin de docs/BESOIN.md dans ce projet.
Ne pas lire de credentials ni modifier Swarm ou d'autres dossiers.
Aucune délégation, aucun agent supplémentaire, aucun service extérieur.
Conserver les montants en centimes côté serveur et ne pas rendre les commandes publiques.
Ne pas installer de packages : Python standard library et ressources locales.
Écrire des tests comportementaux puis un rapport des commandes réellement exécutées.
Ne pas lancer de serveur durable : le formateur réalisera les captures.
Ne pas modifier la base .swarm ni les états de validation : utiliser le handoff.
