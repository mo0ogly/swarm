# Replan — autorité liée à la configuration

R20 inspecte le candidat intégré 2b0694d, sélectionne 33 originaux sous la fenêtre
400000 et démarre une décision finale. La pause concurrente finit en446 avec
88 appels conservés et un avis interrompu ; aucun verdict final n’est accepté.
Le constat de policy_revision est reproduit : après retrait du demandeur, une
approbation et un premier engagement restent admis sur l’ancien mandat.

Options : déclarer des compatibilités entre révisions exige un historique
complet de l’autorité, absent du pilote ; supposer la compatibilité conserverait
le défaut. Décision retenue : égalité stricte policy_revision/configuration pour
les nouvelles demandes, approbations et premiers engagements. Une configuration
appliquée, y compris un changement de justificatif, impose de renouveler le mandat.
Ce choix est explicite dans Admin avant application et dans les deux documents.
Les réponses historiques restent attribuées ; les effets déjà engagés restent
réconciliables sans second effet.

La correction conserve les refus authentifiés, les originaux et les états métier.
Le contre-exemple échoue sur les deux opérations avant correction. 83 cas Go race
(32 principaux,51 sous-cas) passent ensuite ; le CLI refuse les deux anciens
accords puis engage un mandat renouvelé. L’Admin explique cette règle en FR/EN,
avec vingt dispositions, 21 contrôles navigateur et aucun diagnostic inattendu.

Propriétaire : Codex. Prochaine étape : nouvelle remise par l’opération publique,
contrôles frais et revue indépendante. Ne pas réutiliser les inspections R20 ni
réinitialiser ses appels, ses tentatives ou sa décision interrompue. Le programme
reste à un lot accepté sur huit, non qualifié pour diffusion.
