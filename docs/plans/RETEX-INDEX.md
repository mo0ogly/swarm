# Index des RETEX et suites — Swarm

8 novembre 2026 · [English](../en/RETEX-INDEX.md) · [File](FILE-APEX.md)

Les RETEX sont des preuves historiques avec des suites, pas tous des projets
inachevés. Cet index conserve les originaux ; il ne valide ni le code courant ni
leur acceptation native. Chaque carte courte garde un RETEX local ; la clôture
globale ne remplace pas ses critères manquants.
