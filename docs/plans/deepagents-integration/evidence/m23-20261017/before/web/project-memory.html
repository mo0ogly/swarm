Portée et limites de la mémoire
Ce parcours utilise les RETEX vérifiés du projet. L’admission est une décision de l’opérateur local ; elle ne change ni les permissions, ni les budgets, ni les critères de réussite. Les versions remplacées ou retirées restent historiques. Les contextes historiques sont conservés. Chaque départ préparé recontrôle la disponibilité avant son premier envoi ; une conversation déjà en cours doit être réexaminée par son responsable. Une importation conserve les leçons sans les admettre automatiquement dans le projet destinataire.
