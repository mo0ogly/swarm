Les points discriminants sont : service Go unique plutôt qu'autorité du canvas ; brouillon durable et preview sans effet ; apply transactionnel tout ou rien ; idempotence avant garde de révision ; analyse ciblée des périmètres actifs ; preuves liées à un manifeste d'entrées ; présentation séparée ; autorisation revalidée à chaque effet ; mission clôturée refusée sans clone ni réouverture.
